# 모델 평가 선택 지침

- 실제 모델 학습/평가 요구가 있을 때만 적용한다. 설명 변수, 타깃, 시간·그룹·샘플 ID를 확인한 뒤 Train/Validation/Test를 정한다.
- 같은 설비/로트/사람/시계열 구간에서 그룹 누수 또는 미래 정보 유입이 없는지 확인한다. 전처리·인코더·오버샘플링은 **훈련 분할 내부에서만 적합**한다.
- 불균형 분류는 다수 클래스 accuracy만으로 통과를 주장하지 말고 confusion matrix, Macro-F1, Precision/Recall과 목적에 맞는 지표를 사용한다. 회귀는 MAE/RMSE/R²의 한계를 구분한다.
- 단순 기준선과 비교하고 지표의 분모·계산 범위·반복 실험·모델 선택 시점을 기록한다. 과제에 맞지 않는 대규모 탐색과 새 프레임워크를 추가하지 않는다.
- 일반 CSV 집계나 단순 웹앱에 이 스킬을 적용하지 않는다.
