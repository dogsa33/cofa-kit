# Cofa Ready Kit — 단일 Codex 최종 독립 저장소

**별도의 설치기·기존 Fork·패치 파일 없이 사용할 수 있는 공개 단일 Codex 준비 키트입니다.**

이 저장소는 SK하이닉스 AI 해커톤/Cofa Probe의 **비공식 사전 연습 자료**입니다. 실제 시험 과제나 답안은 들어 있지 않습니다. 실제 과제 README 및 주최측 최신 규정이 항상 우선합니다.

## 핵심 원칙

1. **메인 Codex 단일 에이전트**: 하위 에이전트, 병렬 위임, 별도 MCP, 프레임워크 자동 설치를 기본 흐름에 사용하지 않습니다.
2. **Human-in-the-loop는 핵심 정책만**: 최적화 목표, 업무 규칙, 데이터 처리, 개인정보·권한, 대규모 구조 변경 등 **결과를 바꾸는 미결정**만 사용자에게 질문합니다. 한 번에 한 결정. AI 추천은 사용자 승인으로 기록하지 않습니다.
3. **승인된 범위 내 구현은 자율**: 일반 코드 작성·오류 수정·자동 검증 때마다 사용자 승인을 요구하지 않습니다.
4. **명시된 필수 요구 전부 추적**: `dropped`, `skip`, `NOT_RUN`은 필수 요구 검증 성공이 아닙니다. 시간이 부족해 미구현이면 그대로 표시합니다.
5. **작고 단순한 파일 구조**: 기존 코드 우선, 불필요한 문서·폴더·프레임워크 생성 금지. 파일마다 이유를 설명합니다.
6. **사용자 참여형 UAT**: Codex가 실제 포트/입력/조작/기대 결과를 **한 건씩** 안내하고 기다립니다. 사용자가 PASS/FAIL/NOT_RUN/BLOCKED 및 실제 관찰을 알려주면 기록합니다. 수동 PASS는 정책 승인과 다릅니다.
7. **기록과 사실의 분리**: 코드 존재≠실행 성공≠검증 통과. 모든 PASS는 실제 증거, FAIL은 동일 조건 재현과 재검증이 필요합니다.
8. **최종 검토 파일 하나**: 제출 확정 전 실제 과제 폴더에 FINAL_REVIEW.md를 작성하며, 일반 제목과 - 목록으로 구현·검증·예상 질문을 정리합니다. 추가 파일이 금지된 과제에서는 대화 출력으로 대체합니다.

## 첫 사용 — 2단계

1. 시험/연습 컴퓨터에서 과제가 허용하는 방식으로 `git clone --depth 1 https://github.com/dogsa33/cofa-kit.git .cofa-kit`을 **실제 과제 작업 폴더의 터미널**에서 실행합니다. 기존 `.cofa-kit` 폴더가 있으면 무리하게 덮어쓰지 않고 먼저 확인합니다. 과제의 `README.md`, `AGENTS.md`와 원본 데이터는 보존합니다.
2. **현업 확인 질문 목록과 개발 계획·전략, HITL, 개발, Browser UAT, 최종 FINAL_REVIEW.md를 포함한 시작 프롬프트는 [QUICKSTART.md](QUICKSTART.md) 한곳에 있습니다.** 시작 프롬프트를 README에 중복 작성하지 않습니다.

| `skills/cofa-model-eval/` | ML 분할·누수·평가 기준 지침 | 모델 학습 과제일 때만 |
| `scripts/` | 오프라인 보조 도구: CSV, 결정 로그, 원본 보호 | 필요할 때 선택 실행 |
| `examples/` | **기존 분석 CSV·기대값** 및 합성 통근버스 데이터·검산기 | 사전 연습 전용 |
| `tests/` | 이 저장소의 실제 CLI·HITL·합성 데이터 검증 | 로컬 확인 |

## 전체 테스트

Python 3.10 이상, 추가 pip 설치 불필요:

```powershell
python -X utf8 -m unittest discover -s tests -v
```

테스트에 나오는 고의 실패 출력(`FAIL: 보호 파일 변경됨`)은 정상적인 **실패 탐지 테스트**의 내부 관찰입니다. 최종 요약 `OK`와 exit code 0이 실제 테스트 스위트 성공 기준입니다.

## 유지할 데이터 분석 예제

- `examples/defects.csv` 및 `requests.json`: 결측·중복·JSON 전처리 연습
- `examples/joins/`: `(lot_id,wafer_id)` 복합키 조인/행 증폭, 기존 기대 JSON 포함
- `examples/semiconductor/`: 가중 수율·중복 키 차단·SPC I-MR 합성 시계열과 기존 기대 JSON 포함
- `examples/shuttle/`: [공개 통근버스 사전설계](https://github.com/Hantastic-02/h-kit/blob/main/study/04_%ED%86%B5%EA%B7%BC%EB%B2%84%EC%8A%A4_%EC%82%AC%EC%A0%84%EC%84%A4%EA%B3%84.md) 기반 별도 합성 자료와 **독립 검증기**. 앱이나 최적화 정답은 아님.

`data_tools.py`는 해당 분석 연습에 필요한 작은 독립 CLI입니다. **이 저장소는 원본 Fork의 117개 테스트/기타 선택형 MCP 플랫폼을 그대로 이식한 복제품이 아닙니다.** Windows 반복 실패를 일으키던 전체 설치·관리 시스템 대신 목적에 필요한 기능을 간소화해 새로 구성했습니다. 예제 CSV와 기대 JSON은 공개 원본 Fork와 대조해 유지했습니다.

## 실행 제한

사용자의 실제 시험 원본·로그·실제 CSV·사내 정보는 GitHub에 올리지 않습니다. 준비 키트 복제와 과제 제출을 구분합니다. 본 저장소가 시험 도구를 인증하거나 통과를 보증하지 않습니다. 제공된 Codex와 허용 모델만 사용하며, 브라우저 자동화나 외부 시험 데이터 전송은 하지 않습니다. AI 사용 금지 단계(제출 후 서술형 등)에는 키트 작업을 중단합니다.

자료 출처와 기존 원본 라이선스는 [SOURCES.md](SOURCES.md)를 확인하세요.
