# 시작 프롬프트

`.cofa-kit/prompts/SCENARIO.md와 skills/cofa-triage/SKILL.md를 읽고 실제 과제 README, 기존 코드, 데이터, 필수 산출물과 제한사항을 먼저 정리해. 어떤 것도 삭제하거나 새 프레임워크를 설치하지 말고, 필수조건과 예상 검증 기준을 빠짐없이 정리해. **실제 입력 데이터셋 전체를 먼저 열거하고 파일별 용도·행/열·키·결측·중복·참조 오류·변경 차이를 조사한 결과를 보고해. 그 근거로 현업 확인 질문 목록(Q-ID, P0/P1/P2, 답변 영향)을 출력하고 개발 계획·전략도 보고해.** README에 답이 있는 질문은 제외해. **분석·데이터 감사·질문·계획을 모두 보고하기 전에 기능 개발을 시작하지 마.** 현업 문의는 내가 직접 하고, 그다음 중요한 사용자 결정은 한 건씩 제시하고 답을 기다려.`
